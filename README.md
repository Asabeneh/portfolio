# Asabeneh Yetayeh Portfolio

Research-backed, responsive, single-page portfolio for Asabeneh Yetayeh.

## What is included
- `index.html`: Portfolio structure and content
- `styles.css`: Custom visual system, responsive layout, and motion
- `script.js`: Reveal animations, animated counters, dynamic year
- `RESEARCH.md`: Source list and verified metrics snapshot used to build content

## Research baseline
This portfolio content is based on public data collected on 2026-03-07 from:
- GitHub public profile and repository APIs
- Asabeneh personal website pages (home/about/services/testimonials/contents)
- Washera Academy YouTube channel page
- LinkedIn public profile snippets

See `RESEARCH.md` for details and caveats.

## Run locally
From the repository root:

```bash
python3 -m http.server 8080
```

Then open:

`http://localhost:8080`
